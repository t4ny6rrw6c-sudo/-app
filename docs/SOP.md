# 현장 부적합 관리 앱 — 운영 표준 절차서 (SOP)

**문서번호**: SOP-NCM-001  
**버전**: 1.0  
**작성일**: 2026-06-23  
**적용 대상**: 현장 안전 점검 담당자, 시설 관리자

---

## 1. 개요

현장 점검 중 발견된 부적합 사항을 모바일로 기록하고, 담당자에게 SMS / 이메일 / PDF 형태로 발송하는 React Native 기반 모바일 앱입니다.

### 1.1 주요 기능

| 기능 | 설명 |
|---|---|
| 부적합 발행 | 현장 정보, 체크리스트, 사진, GPS, 서명 포함 양식 작성 |
| 점검 샘플 조회 | 6개 카테고리별 12개 법정 점검 항목 확인 |
| 발송 | SMS / 이메일(PDF 첨부) / PDF 공유 |
| 이력 관리 | 발행 이력 조회 및 상태 변경 (미조치 → 조치 중 → 완료) |

### 1.2 점검 카테고리

| 아이콘 | 카테고리 | 근거 법령 |
|---|---|---|
| 🏗️ | 비계 | 산업안전보건기준에 관한 규칙 제55~76조 |
| 🔥 | 화기작업 | 제241~249조 |
| ⛔ | 밀폐공간 | 제618~641조 |
| ⚡ | 전기작업 | 제301~321조 |
| 🪜 | 고소작업 | 제42~59조 |
| 🚧 | 중장비 | 제98~171조 |

## 4. 앱 실행 방법

### Step 1. 개발 서버 시작

```bash
npm start
# 또는
npx expo start
```

터미널에 아래와 같은 QR 코드가 표시됩니다:

```
Metro waiting on exp://192.168.x.x:8081
  › Press a │ open Android
  › Press i │ open iOS simulator
  › Press w │ open web

  ▄▄▄▄▄▄▄▄▄▄▄
  █ ▄▄▄▄▄ █▀▄
  █ █   █ █▄▀
  █ █▄▄▄█ █▀▄
  █▄▄▄▄▄▄▄█
```

### Step 2. 스마트폰에서 실행

#### Android

1. **Expo Go** 앱 실행
2. **"Scan QR Code"** 버튼 탭
3. 터미널의 QR 코드 스캔

#### iOS

1. 기본 **카메라 앱** 실행
2. QR 코드 스캔
3. 상단 배너 탭 → Expo Go에서 자동 오픈

> ⚠️ 폰과 PC가 동일한 Wi-Fi에 연결되어 있어야 합니다.  
> 연결 안 될 경우: 터미널에서 `s` 키 → tunnel 모드로 전환

### Step 3. (선택) 플랫폼별 에뮬레이터

```bash
npm run android   # Android Studio 에뮬레이터
npm run ios       # iOS 시뮬레이터 (macOS + Xcode 필요)
```

## 5. 화면별 사용 방법

### 5.1 홈 탭 (🏠)

앱 실행 시 기본으로 표시되는 화면입니다.

- **상단 통계**: 미조치 / 조치 중 / 완료 / 전체 건수 한눈에 확인
- **부적합 목록**: 최신순 정렬, 왼쪽 색상 바로 중요도 구분
- **카드 탭**: 부적합 상세 화면으로 이동

| 색상 | 중요도 |
|---|---|
| 🟢 초록 | 낮음 |
| 🟡 주황 | 보통 |
| 🟠 진주황 | 높음 |
| 🔴 빨강 | 긴급 |

---

### 5.2 새 부적합 탭 (➕)

현장에서 부적합 사항 발견 시 사용합니다.

#### 작성 순서

```
① 기본 정보 입력
   → 발행일 (자동 입력) / 점검 구역 / 점검자 이름

② 점검 분류 선택
   → 비계 / 화기작업 / 밀폐공간 / 전기작업 / 고소작업 / 중장비

③ 중요도 선택
   → 낮음 / 보통 / 높음 / 긴급

④ 부적합 내용 입력
   → 부적합 내용 (필수) / 조치 요청사항 / 조치 기한

⑤ 체크리스트 결과 입력
   → 선택한 카테고리의 12개 항목에 대해 적합 / 부적합 / N/A 선택

⑥ 현장 사진 첨부 (선택, 최대 5장)
   → [촬영] 버튼: 카메라로 직접 촬영
   → [갤러리] 버튼: 갤러리에서 선택

⑦ GPS 위치 기록 (선택)
   → [현재 위치 가져오기] 버튼 탭
   → 위도/경도 자동 기록

⑧ 점검자 서명 (선택)
   → 서명란 탭 → 손가락으로 서명 → [저장]

⑨ 담당자 정보 입력 (필수)
   → 담당자 이름 / 연락처 / 이메일

⑩ [💾 부적합 저장] 버튼 탭
```

> ✅ 필수 항목: 점검 구역, 점검자, 부적합 내용, 담당자 이름, 담당자 연락처

---

### 5.3 점검 샘플 탭 (📌)

현장 점검 전 참고용 체크리스트를 확인합니다.

```
① 카테고리 카드 탭 (비계 / 화기 / 밀폐 / 전기 / 고소 / 중장비)
② 법적 근거 및 12개 점검 항목 확인
③ 새 부적합 작성 시 동일 카테고리 선택 → 체크리스트 자동 생성
```

---

### 5.4 이력 탭 (📂)

과거 발행한 부적합 전체 이력을 조회합니다.

- **필터**: 전체 / 미조치 / 조치 중 / 완료
- 카드를 탭하면 상세 화면으로 이동

---

### 5.5 부적합 상세 화면

홈 또는 이력 탭에서 카드를 탭하면 진입합니다.

#### 상태 변경

화면 하단 **[상태 변경]** 버튼으로 처리 상태를 업데이트합니다:

```
미조치 → 조치 중 → 완료
```

#### 삭제

우측 상단 **[삭제]** 탭 → 확인 팝업 → 삭제 완료

## 6. 부적합 발송 방법

상세 화면 하단 **[📤 담당자 발송]** 섹션에서 선택합니다.

### 6.1 SMS 발송 (💬)

```
[SMS 발송] 버튼 탭
→ 기기의 문자 앱 자동 실행
→ 담당자 번호 자동 입력
→ 부적합 내용 텍스트 자동 입력
→ [전송] 버튼 탭
```

> ⚠️ SMS 미지원 기기(태블릿 등) 에서는 이메일 발송을 사용하세요.

### 6.2 이메일 발송 (📧)

```
[이메일 발송] 버튼 탭
→ 기기의 이메일 앱 자동 실행
→ 수신자: 담당자 이메일 자동 입력
→ 제목: [부적합 발행] NC-번호 — 점검구역 (중요도)
→ 본문: 부적합 내용 텍스트
→ 첨부: 부적합 양식 PDF 파일
→ [전송] 버튼 탭
```

> ✅ 이메일은 PDF가 자동 첨부되어 공식 문서로 전달됩니다.

### 6.3 PDF 공유 (📄)

```
[PDF 공유] 버튼 탭
→ PDF 파일 자동 생성 (부적합 양식 전체 내용)
→ 기기 공유 시트 표시
→ 원하는 앱 선택하여 전달
   예) 카카오톡, 문자, 이메일, 드라이브, AirDrop 등
```

### 발송 방식 결정 기준

```
담당자 연락처만 있는 경우  → SMS 발송
담당자 이메일이 있는 경우  → 이메일 발송 (PDF 첨부 공식 문서)
공식 문서 배포 필요       → PDF 공유
SMS/이메일 모두 불가      → PDF 공유 → 원하는 앱으로 전달
```

## 7. 데이터 관리

- 모든 부적합 데이터는 **기기 내부에 로컬 저장** (백엔드 서버 불필요)
- 앱 삭제 시 데이터 삭제됨 → 중요 기록은 PDF로 보관 권장
- 기기 변경 시 이전 기록은 이전되지 않음

## 8. 문제 해결 (FAQ)

### Q. QR 코드 스캔 후 앱이 열리지 않아요

```
확인 사항:
1. 폰과 PC가 동일한 Wi-Fi에 연결되어 있는지 확인
2. 터미널에서 's' 키 입력 → Tunnel 모드로 전환
3. 방화벽이 8081 포트를 허용하는지 확인
4. npm start 재실행
```

### Q. GPS 위치를 가져오지 못해요

```
확인 사항:
1. 스마트폰 설정 → 위치 서비스 활성화
2. Expo Go 앱에 위치 권한 허용
3. 실내에서는 GPS 정확도가 낮을 수 있음 (야외 이동 권장)
```

### Q. 카메라/갤러리가 작동하지 않아요

```
확인 사항:
1. Expo Go 앱에 카메라/사진 권한 허용
   → 스마트폰 설정 → 앱 → Expo Go → 권한
2. 앱 재실행 후 재시도
```

### Q. SMS 발송이 안 돼요

```
확인 사항:
1. 태블릿/Wi-Fi 전용 기기는 SMS 불가 → 이메일 발송 사용
2. 이메일 발송 또는 PDF 공유로 대체
```

### Q. 이메일 앱이 열리지 않아요

```
확인 사항:
1. 기기에 이메일 앱(Gmail, 네이버 메일 등) 설치 및 계정 로그인 여부 확인
2. 이메일 앱 미설치 시 → PDF 공유로 대체
```

### Q. 개발 서버 실행 시 에러가 나요

```bash
# 캐시 초기화 후 재실행
npx expo start --clear

# node_modules 재설치
rm -rf node_modules && npm install && npm start
```
