# 안전점검 체크리스트 생성 Skill

위험성평가 결과 또는 작업명을 기반으로 공정별 안전점검 체크리스트를 생성하고
Excel 파일로 출력합니다. 현장 순회점검 및 작업 전 자체점검에 활용합니다.

---

## 사전 확인

아래 파일이 있으면 읽어서 점검 항목 구성에 반영합니다:
- `.claude/safety-guide/guide.txt` — 사내 안전가이드 (점검 기준 인용)
- 기존 위험성평가 Excel 파일 (사용자가 경로/내용 제공 시 → 감소대책을 점검 항목으로 자동 변환)

---

## 진행 절차

### STEP 1 — 기본 정보 수집

한 번에 하나씩 질문하세요:

1. **점검 대상 작업명** (또는 공정/설비명)
2. **점검 유형**
   - 작업 전 자체점검 (매일/매 작업 전)
   - 정기 순회점검 (주간/월간)
   - 특별점검 (사고 후, 계절별)
3. **점검 주기** (매일 / 주 1회 / 월 1회 등)
4. **점검자 직책**
5. **사업장명**

---

### STEP 2 — 점검 항목 도출

위험성평가 결과가 있으면 **감소대책을 점검 항목으로 변환**합니다.

변환 규칙:
- `[공학적] 방호장치 설치` → `방호장치 설치 및 정상 작동 여부`
- `[관리적] 작업허가서 발급` → `작업허가서 발급 및 현장 비치 여부`
- `[보호구] 안전대 착용` → `안전대 착용 및 체결 상태 확인`

위험성평가 결과가 없으면 작업명 기반으로 아래 분류에 따라 항목을 도출합니다:

**점검 항목 분류:**
| 분류 | 세부 항목 예시 |
|------|-------------|
| 설비·기계 | 방호장치, 비상정지, 안전밸브, 접지 |
| 작업 환경 | 통로 확보, 정리정돈, 조명, 환기 |
| 보호구 | 착용 여부, 상태 이상 여부 |
| 작업 절차 | 절차서 비치, LOTO 적용, 허가서 발급 |
| 유해물질 | 보관 상태, 표지 부착, 누출 여부 |
| 비상대비 | 소화기 위치·압력, 비상구 확보, 응급처치함 |

안전가이드에 점검 기준이 명시된 경우 해당 내용을 인용하고 `[가이드 X절]` 표기합니다.

각 항목마다 사용자가 확인·수정할 수 있도록 목록을 제시합니다.

---

### STEP 3 — 판정 기준 확인

각 점검 항목의 판정 기준을 사용자와 확인합니다:

- **양호** / **불량** / **해당없음** 3단계 (기본)
- 또는 **O / X / N/A**

불량 판정 시 **즉시조치 / 개선요청** 구분 여부를 사용자에게 확인합니다.

---

### STEP 4 — Excel 체크리스트 생성

```python
import openpyxl
from openpyxl.styles import Font, Alignment, PatternFill, Border, Side, GradientFill
from openpyxl.utils import get_column_letter
from datetime import date
import os

checklist_data = {
    "사업장명": "",
    "작업명": "",
    "점검유형": "",    # "작업전 자체점검" / "정기 순회점검" / "특별점검"
    "점검주기": "",
    "점검자직책": "",
    "점검일": str(date.today()),
    "sections": [
        # {
        #   "분류": "설비·기계",
        #   "items": [
        #     {
        #       "번호": 1,
        #       "점검항목": "방호장치 설치 및 정상 작동 여부",
        #       "점검기준": "모든 위험 부위에 방호장치 설치, 비가동 시 작동 불가 구조",
        #       "출처": "[가이드 3장]",   # 없으면 "[KOSHA]"
        #       "관련위험요인": "협착",    # 위험성평가 연계 시 기재
        #     },
        #   ]
        # },
    ]
}

def thin_border():
    s = Side(style='thin')
    return Border(left=s, right=s, top=s, bottom=s)

def thick_left_border():
    return Border(
        left=Side(style='medium'), right=Side(style='thin'),
        top=Side(style='thin'),    bottom=Side(style='thin')
    )

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "안전점검표"

col_widths = [6, 14, 32, 32, 12, 10, 10, 10, 20]
for i, w in enumerate(col_widths, 1):
    ws.column_dimensions[get_column_letter(i)].width = w

hf    = PatternFill("solid", fgColor="1F4E79")
hfont = Font(name="맑은 고딕", bold=True, color="FFFFFF", size=10)
sf    = PatternFill("solid", fgColor="BDD7EE")
sec_font = Font(name="맑은 고딕", bold=True, size=10)
data_font = Font(name="맑은 고딕", size=10)
center = Alignment(horizontal="center", vertical="center", wrap_text=True)
left   = Alignment(horizontal="left",   vertical="center", wrap_text=True)
info_fill = PatternFill("solid", fgColor="D6E4F0")
label_font = Font(name="맑은 고딕", bold=True, size=10)

# 제목
ws.row_dimensions[1].height = 38
ws.merge_cells("A1:I1")
ws["A1"] = f"안 전 점 검 표 — {checklist_data['점검유형']}"
ws["A1"].font = Font(name="맑은 고딕", bold=True, size=15, color="FFFFFF")
ws["A1"].alignment = center
ws["A1"].fill = hf

# 기본 정보 (2~3행)
info_pairs = [
    ("A2","B2","사업장명","C2","D2", checklist_data["사업장명"],
     "E2","F2","점검유형","G2","I2", checklist_data["점검유형"]),
    ("A3","B3","작업명",  "C3","D3", checklist_data["작업명"],
     "E3","F3","점검주기","G3","I3", checklist_data["점검주기"]),
    ("A4","B4","점검자",  "C4","D4", checklist_data["점검자직책"],
     "E4","F4","점검일",  "G4","I4", checklist_data["점검일"]),
]
for row_data in info_pairs:
    lc1,lc2,lv1,vc1,vc2,vv1,lc3,lc4,lv2,vc3,vc4,vv2 = row_data
    ws.merge_cells(f"{lc1}:{lc2}"); ws[lc1]=lv1
    ws[lc1].font=label_font; ws[lc1].fill=info_fill
    ws[lc1].alignment=center; ws[lc1].border=thin_border()
    ws.merge_cells(f"{vc1}:{vc2}"); ws[vc1]=vv1
    ws[vc1].font=data_font; ws[vc1].alignment=left; ws[vc1].border=thin_border()
    ws.merge_cells(f"{lc3}:{lc4}"); ws[lc3]=lv2
    ws[lc3].font=label_font; ws[lc3].fill=info_fill
    ws[lc3].alignment=center; ws[lc3].border=thin_border()
    ws.merge_cells(f"{vc3}:{vc4}"); ws[vc3]=vv2
    ws[vc3].font=data_font; ws[vc3].alignment=left; ws[vc3].border=thin_border()

for r in [2,3,4]:
    ws.row_dimensions[r].height = 18

# 컬럼 헤더 (5행)
ws.row_dimensions[5].height = 30
headers = ["No.", "분류", "점검 항목", "점검 기준", "출처", "양호", "불량", "해당없음", "조치사항"]
for i, h in enumerate(headers, 1):
    col = get_column_letter(i)
    ws[f"{col}5"] = h
    ws[f"{col}5"].font = hfont
    ws[f"{col}5"].fill = hf
    ws[f"{col}5"].alignment = center
    ws[f"{col}5"].border = thin_border()

# 데이터 행
ROW = 6
item_num = 1
for section in checklist_data["sections"]:
    # 분류 헤더행
    ws.row_dimensions[ROW].height = 22
    ws.merge_cells(f"A{ROW}:I{ROW}")
    ws[f"A{ROW}"] = f"▶ {section['분류']}"
    ws[f"A{ROW}"].font = sec_font
    ws[f"A{ROW}"].fill = sf
    ws[f"A{ROW}"].alignment = left
    ws[f"A{ROW}"].border = thin_border()
    ROW += 1

    for item in section["items"]:
        ws.row_dimensions[ROW].height = 42
        row_vals = [
            ("A", item_num), ("B", section["분류"]),
            ("C", item["점검항목"]), ("D", item["점검기준"]),
            ("E", item.get("출처","")),
            ("F","□"), ("G","□"), ("H","□"), ("I",""),
        ]
        for col, val in row_vals:
            c = ws[f"{col}{ROW}"]
            c.value = val
            c.font = data_font
            c.border = thin_border()
            c.alignment = center if col in "ABEFGH" else left
        item_num += 1
        ROW += 1

# 하단 서명란
ws.row_dimensions[ROW].height = 20
ws.merge_cells(f"A{ROW}:I{ROW}")
ws[f"A{ROW}"] = "점검자 서명: _______________   확인자 서명: _______________   날짜: _______________"
ws[f"A{ROW}"].font = Font(name="맑은 고딕", size=10)
ws[f"A{ROW}"].alignment = left
ws[f"A{ROW}"].border = thin_border()
ws[f"A{ROW}"].fill = PatternFill("solid", fgColor="F2F2F2")

output_dir = os.getcwd()
fname = f"안전점검표_{checklist_data['작업명']}_{checklist_data['점검일']}.xlsx".replace(" ","_")
wb.save(os.path.join(output_dir, fname))
print(f"✅ 안전점검표 생성: {fname}")
print(f"   총 점검 항목 수: {item_num - 1}개")
```

## 위험성평가 연계 방법

위험성평가 결과에서 점검 항목을 자동으로 가져오려면:
1. 위험성평가 Excel 파일을 채팅에 첨부하거나 내용을 붙여넣습니다.
2. 감소대책 컬럼의 각 항목이 자동으로 점검 항목으로 변환됩니다.
3. 위험성 수준 높음(H) 이상 항목은 **굵게 강조** 처리됩니다.

## 관련 Skill

- `/위험성평가` — 위험요인 발굴 및 대책 수립 (점검 항목의 원천)
- `/TBM` — 당일 작업 안전 미팅 (점검 결과 공유)
- `/아차사고분석` — 점검 중 발견된 이상 상황 분석

## 주의사항

- 점검 항목은 실제 현장 상황에 맞게 추가·삭제할 수 있습니다.
- 불량 항목은 즉시 작업 중지 또는 개선 요청을 통해 조치합니다.
- 점검 기록은 **3년 이상 보존**합니다 (산업안전보건법 제57조).
