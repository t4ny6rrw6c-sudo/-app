# 위험성평가서 검토 Skill

협력업체 또는 시설부서가 제출한 위험성평가서를 검토하여 부적합 사항을 레포트로 작성합니다.
검토 기준은 LG화학 작업안전가이드(등록된 경우) 및 산업안전보건법(2024)을 적용합니다.

---

## STEP 0 — 준비

### 1. LG화학 작업안전가이드 로드

`.claude/safety-guide/guide.txt` 파일이 있으면 읽어서 감소대책 적절성 판단 기준으로 사용합니다.
없으면 KOSHA 기준을 적용하고 사용자에게 안내합니다:
> "LG화학 가이드 미등록 상태입니다. KOSHA 기준으로 검토합니다. 가이드 파일을 채팅에 첨부하면 LG화학 기준이 자동 반영됩니다."

### 2. 평가서 입력 안내

사용자에게 아래 중 하나를 요청합니다:
> "검토할 위험성평가서를 아래 방법 중 하나로 입력해 주세요.
> - **방법 1**: 평가서 내용(표 전체)을 채팅창에 붙여넣기
> - **방법 2**: 파일(Excel/Word/PDF)을 채팅에 첨부
>
> 입력이 완료되면 검토를 시작하겠습니다."

---

## STEP 1 — 기본 정보 확인

입력된 평가서에서 아래 항목을 파악하고, 누락된 항목은 부적합으로 기록합니다.

| 확인 항목 | 적합 기준 |
|-----------|-----------|
| 사업장명 | 기재 여부 |
| 작업명 | 기재 여부 |
| 평가일 | 기재 여부 (YYYY-MM-DD 또는 동등 형식) |
| 평가자 | 성명 기재 여부 |
| 작업장소 | 구체적 장소 기재 여부 (건물/공정라인/위치) |

---

## STEP 2 — 항목별 검토 (5개 기준 적용)

각 평가 항목(행)마다 아래 5가지 기준으로 검토합니다.

---

### 검토 기준 1: 유해위험요인 구체성

**적합:** `[위험유형] 원인/조건 → 예상사고` 형식이 충족된 경우

적합 예시:
- `[협착] 프레스 슬라이드 행정 중 금형 내 손 삽입 → 손가락 절단`
- `[추락] 고소작업대 3m 높이 볼트 체결 시 안전대 미체결 → 추락 사망`

**부적합 판단 기준:**

| 부적합 유형 | 예시 |
|-------------|------|
| **[F1-A] 원인 불명확** | "추락" / "협착 위험" / "위험요인 있음" |
| **[F1-B] 예상사고 미기재** | "볼트 체결 시 안전대 미착용" (→ 사고 결과 없음) |
| **[F1-C] 위험유형 미기재** | 위험유형 코드([추락], [협착] 등) 없음 |
| **[F1-D] 추상적·포괄적** | "기계 사용 시 위험" / "작업 중 부상" |

---

### 검토 기준 2: 유해위험기계기구 기재 적정성

**법정 유해위험기계기구 12종:**
프레스 / 전단기·절곡기 / 크레인 / 리프트 / 압력용기 / 롤러기 / 사출성형기 / 고소작업대 / 컨베이어 / 산업용 로봇 / 지게차 / 양중기

**부적합 판단 기준:**

| 부적합 유형 | 판단 방법 |
|-------------|-----------|
| **[F2-A] 누락** | 위험요인에 기계 키워드(지게차/크레인/프레스/고소/컨베이어/리프트/로봇/사출/롤러/압력용기/절곡기/양중기)가 있는데 기계기구 컬럼이 비어 있거나 "해당없음" 기재 |
| **[F2-B] 미등재 명칭** | 기재된 명칭이 12종 목록에 없음 (예: "이동식사다리", "체인블록", "파워툴") |
| **[F2-C] 불일치** | 화학적·인간공학적 위험요인인데 기계기구 기재 / 기계기구와 위험유형이 논리적으로 맞지 않음 |

---

### 검토 기준 3: 위험성 수준 산정 적절성

**위험성 수준 체계:**

| 점수 | 수준 |
|------|------|
| 20~25 | 매우 높음(VH) |
| 15~19 | 높음(H) |
| 9~14  | 보통(M) |
| 4~8   | 낮음(L) |
| 1~3   | 매우 낮음(VL) |

**부적합 판단 기준:**

| 부적합 유형 | 판단 방법 |
|-------------|-----------|
| **[F3-A] 가능성×중대성 불일치** | 가능성×중대성 값과 기재된 점수가 다름 |
| **[F3-B] 수준 판정 오류** | 점수와 수준 분류가 위 표와 불일치 |
| **[F3-C] 과소 산정 의심** | 사망·장애 수준 위험(크레인 낙하, 고소 추락, 밀폐공간 등)의 중대성이 3 이하 기재 |
| **[F3-D] 가능성 기준 불일치** | 매일 반복 작업인데 가능성 1~2 / 연간 1회 작업인데 가능성 4~5 기재 |

---

### 검토 기준 4: 감소대책 구체성

**적합 기준:**
- 동사+구체적 행동 형식 (`~한다`, `~을 확인한다`, `~를 착용한다`)
- LG화학 가이드 등록 시: 가이드 준수사항 인용 포함 여부

**부적합 판단 기준:**

| 부적합 유형 | 예시 |
|-------------|------|
| **[F4-A] 추상적 대책** | "주의한다" / "안전하게 작업한다" / "교육 실시" |
| **[F4-B] 보호구만 기재** | 제거→대체→공학적→관리적 단계 없이 보호구만 기재 |
| **[F4-C] 대책 미기재** | 빈 칸 또는 "해당없음" |
| **[F4-D] LG화학 가이드 미반영** | 가이드 등록 시, 해당 위험에 대한 가이드 준수사항이 전혀 반영되지 않음 |

---

### 검토 기준 5: 필수 관리 항목 누락

| 확인 항목 | 부적합 유형 | 기준 |
|-----------|-------------|------|
| 담당자 | **[F5-A]** | 이름 또는 직책 미기재 |
| 완료예정일 | **[F5-B]** | 날짜 미기재 |
| VH·H 항목 개선계획 | **[F5-C]** | 매우 높음·높음 수준인데 즉시 개선 계획 없음 |

## STEP 4 — Excel 레포트 출력 (선택)

사용자가 Excel 파일로 출력을 원하는 경우 아래 Python 스크립트를 실행합니다.

```python
import openpyxl
from openpyxl.styles import Font, Alignment, PatternFill, Border, Side
from openpyxl.utils import get_column_letter
from datetime import date
import os

# ── 검토 결과 데이터 (위 STEP 3 분석 결과를 여기에 채웁니다) ──
REVIEW_META = {
    "사업장명": "",
    "작업명":   "",
    "평가일":   "",
    "평가자":   "",
    "작업장소": "",
    "검토일":   str(date.today()),
}

# 부적합 항목 목록
# severity: "즉시수정" / "수정권고"
FINDINGS = [
    # 예시:
    # {
    #     "no": 1,
    #     "공정단계": "지게차 주행",
    #     "현재내용": "충돌 위험",
    #     "부적합코드": "F1-A",
    #     "부적합유형": "위험요인 구체성",
    #     "부적합내용": "위험유형·원인·예상사고 모두 미기재",
    #     "개선방향": '[충돌] 교차로에서 지게차와 보행자 혼재 시 시야 불량으로 충돌 → 압사',
    #     "severity": "즉시수정",
    # },
]

# ── 스타일 함수 ──
def thin():
    s = Side(style='thin')
    return Border(left=s, right=s, top=s, bottom=s)

def hfill(color): return PatternFill("solid", fgColor=color)
def hfont(color="000000", bold=False, size=10):
    return Font(name="맑은 고딕", bold=bold, color=color, size=size)
center = Alignment(horizontal="center", vertical="center", wrap_text=True)
left   = Alignment(horizontal="left",   vertical="center", wrap_text=True)

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "위험성평가 검토 레포트"

# 컬럼 너비
col_w = [5, 16, 20, 14, 14, 30, 30, 12]
for i, w in enumerate(col_w, 1):
    ws.column_dimensions[get_column_letter(i)].width = w

# 제목 행
ws.row_dimensions[1].height = 40
ws.merge_cells("A1:H1")
ws["A1"] = "위험성평가서 검토 레포트  (LG화학 기준)"
ws["A1"].font  = Font(name="맑은 고딕", bold=True, size=15, color="FFFFFF")
ws["A1"].fill  = hfill("1F4E79")
ws["A1"].alignment = center

# 기본 정보 행
info_fill = hfill("D6E4F0")
info_lbl  = Font(name="맑은 고딕", bold=True, size=10)
info_val  = Font(name="맑은 고딕", size=10)
info_rows = [
    (2, "A2:B2", "사업장명", "C2:D2", REVIEW_META["사업장명"],
        "E2:F2", "평가일",   "G2:H2", REVIEW_META["평가일"]),
    (3, "A3:B3", "작업명",   "C3:D3", REVIEW_META["작업명"],
        "E3:F3", "작업장소", "G3:H3", REVIEW_META["작업장소"]),
    (4, "A4:B4", "평가자",   "C4:D4", REVIEW_META["평가자"],
        "E4:F4", "검토일",   "G4:H4", REVIEW_META["검토일"]),
]
for r, lc1, lt1, vc1, vt1, lc2, lt2, vc2, vt2 in info_rows:
    ws.row_dimensions[r].height = 18
    for rng, txt, is_label in [
        (lc1, lt1, True), (vc1, vt1, False),
        (lc2, lt2, True), (vc2, vt2, False)
    ]:
        ws.merge_cells(rng)
        c = rng.split(":")[0]
        ws[c] = txt
        ws[c].font = info_lbl if is_label else info_val
        ws[c].fill = info_fill if is_label else PatternFill()
        ws[c].alignment = center if is_label else left
        ws[c].border = thin()

# 헤더 행 (5행)
ws.row_dimensions[5].height = 36
headers = [
    ("A5", "No."), ("B5", "작업\n공정/단계"), ("C5", "현재 기재 내용"),
    ("D5", "부적합\n코드"), ("E5", "부적합\n유형"),
    ("F5", "부적합 내용"), ("G5", "개선 방향"), ("H5", "중요도"),
]
for cell, txt in headers:
    ws[cell] = txt
    ws[cell].font  = Font(name="맑은 고딕", bold=True, color="FFFFFF", size=10)
    ws[cell].fill  = hfill("1F4E79")
    ws[cell].alignment = center
    ws[cell].border = thin()

# 데이터 행
ROW_S = 6
for i, f in enumerate(FINDINGS):
    r = ROW_S + i
```
