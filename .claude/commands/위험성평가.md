# 작업위험성평가 지원 Skill

사용자와 대화하며 작업위험성평가표를 작성하고 Excel 파일로 출력합니다.
작성 완료 후 유해위험기계기구 누락·오기 여부를 자동 검토하여 Excel에 붉은 폰트로 표시합니다.

## 진행 절차

아래 순서대로 사용자에게 질문하며 정보를 수집하세요. 단계별로 완료된 후 다음 단계로 진행합니다.

---

### STEP 1 — 기본 정보 수집

사용자에게 다음 항목을 질문하세요:

1. **사업장명** (회사/현장 이름)
2. **평가 대상 작업명** (예: 용접 작업, 지게차 하역 작업, 외벽 도장 작업 등)
3. **평가일** (오늘 날짜 기본 제안)
4. **평가자 이름**
5. **작업 장소** (건물동, 공정라인, 현장 위치 등)

---

### STEP 2 — 작업 공정/단계 도출

수집한 작업명을 바탕으로:
1. 해당 작업의 세부 단계(공정)를 **5~10개** 제안하세요.
2. 사용자가 수정·추가·삭제할 수 있도록 합니다.
3. 최종 공정 단계 목록을 확정합니다.

**업종별 참고 유해위험요인 유형:**
- 기계적: 협착, 끼임, 절단, 충돌, 전도
- 전기적: 감전, 정전기, 아크
- 화학적: 유해물질 흡입, 피부 접촉, 폭발
- 물리적: 소음, 진동, 고온, 저온, 방사선
- 인간공학: 중량물 취급, 반복 동작, 부자연 자세
- 추락/낙하: 고소 작업, 낙하물
- 화재/폭발: 인화성 물질, 가스 누출

---

### STEP 3 — 공정별 유해위험요인 및 유해위험기계기구 발굴

각 공정 단계마다 순서대로:

1. 해당 단계에서 **발생 가능한 유해위험요인** 2~4개를 제안하세요 (원인 및 현상 포함)
2. 해당 단계에서 사용되는 **유해위험기계기구**를 기재하도록 안내하세요
3. 사용자가 확인·수정하도록 합니다

유해위험요인 작성 형식:
> **[위험요인 유형]** 원인/현상 → 발생 가능 사고/질병

예시:
> **[협착]** 컨베이어 가동 중 점검 → 손가락 협착
> **[추락]** 2m 이상 고소작업 중 안전대 미착용 → 추락 재해

**산업안전보건법상 유해위험기계기구 목록 (참고):**
| 기계기구명 | 관련 키워드 |
|-----------|------------|
| 프레스 | 프레스, 펀칭, 금형, 단조 |
| 전단기·절곡기 | 전단, 절단, 절곡, 벤딩 |
| 크레인 | 크레인, 호이스트, 인양, 줄걸이 |
| 리프트 | 리프트, 화물 승강 |
| 압력용기 | 압력, 보일러, 탱크, 고압 |
| 롤러기 | 롤러, 압연, 롤 |
| 사출성형기 | 사출, 성형, 몰드 |
| 고소작업대 | 고소, 2m 이상, 작업발판, 비계 |
| 컨베이어 | 컨베이어, 벨트, 이송 |
| 산업용 로봇 | 로봇, 자동화, 매니퓰레이터 |
| 지게차 | 지게차, 포크리프트, 하역 |
| 양중기 | 체인블록, 전동호이스트, 달기기구 |

기계기구가 없는 단계는 **"해당없음"** 으로 기재합니다.

### STEP 4 — 위험성 크기 산정

각 유해위험요인에 대해 **가능성 × 중대성** 방식으로 평가합니다.

**가능성 (발생 빈도/가능성):**
| 등급 | 점수 | 기준 |
|------|------|------|
| 매우 높음 | 5 | 매일 또는 매우 자주 발생 가능 |
| 높음 | 4 | 주 1회 이상 발생 가능 |
| 보통 | 3 | 월 1회 이상 발생 가능 |
| 낮음 | 2 | 연 1회 미만 발생 가능 |
| 매우 낮음 | 1 | 거의 발생하지 않음 |

**중대성 (사고 결과의 심각도):**
| 등급 | 점수 | 기준 |
|------|------|------|
| 매우 심각 | 5 | 사망 또는 영구 장애 |
| 심각 | 4 | 6개월 이상 요양 필요 부상 |
| 보통 | 3 | 1개월 이상 요양 필요 부상 |
| 경미 | 2 | 1개월 미만 치료 |
| 미미 | 1 | 응급처치 수준 |

**위험성 수준 판정:**
| 점수 | 위험성 수준 | 조치 |
|------|------------|------|
| 20~25 | 매우 높음 (VH) | 즉시 작업 중지, 긴급 대책 수립 |
| 15~19 | 높음 (H) | 즉시 개선 필요 |
| 9~14 | 보통 (M) | 단기 내 개선 계획 수립 |
| 4~8 | 낮음 (L) | 현 수준 관리, 정기 모니터링 |
| 1~3 | 매우 낮음 (VL) | 허용 가능, 기록 유지 |

---

### STEP 5 — 위험성 감소대책 수립

위험성 수준이 **보통(M) 이상**인 항목에 대해 우선적으로 감소대책을 수립합니다.

대책 수립 우선순위 (제거 → 대체 → 공학적 → 관리적 → 보호구):

1. **제거**: 위험 요인 자체를 없앰
2. **대체**: 덜 위험한 방법/재료로 변경
3. **공학적 대책**: 방호장치, 격리, 환기 설치
4. **관리적 대책**: 작업절차서, 교육, 표지판, 출입 통제
5. **개인보호구**: 안전모, 안전대, 보호장갑 등

각 위험요인마다 위 우선순위에 따라 **1개 이상의 대책**을 제시하세요.

---

### STEP 6 — 유해위험기계기구 검토 (자동 수행)

Excel 생성 전에 아래 기준으로 각 항목을 검토하여 `review_issues` 필드에 결과를 기록합니다.
이 단계는 Claude가 자동으로 수행하며, 이슈가 있는 항목은 Excel에 붉은 폰트로 표시됩니다.

**검토 기준:**

| 검토 항목 | 판단 기준 | 오류 코드 |
|----------|----------|----------|
| **누락** | 공정단계·유해위험요인 텍스트에 기계기구 관련 키워드가 있으나 기계기구 필드가 비어있거나 "해당없음" | `[누락]` |
| **미등재 기계기구** | 기재된 기계기구가 법정 유해위험기계기구 목록에 없는 명칭 | `[미등재]` |
| **불일치** | 기재된 기계기구와 위험요인 유형·내용이 논리적으로 맞지 않음 (예: 화학적 위험에 크레인 기재) | `[불일치]` |
| **형식 오류** | 기계기구명이 불명확하거나 약어·비표준 명칭 사용 | `[형식오류]` |

검토 결과 이슈가 없으면 `review_issues = ""` (정상)으로 표시합니다.

---

def get_risk_level(score):
    if score >= 20: return ("매우 높음", "VH", "FF0000")
    elif score >= 15: return ("높음", "H", "FF6600")
    elif score >= 9: return ("보통", "M", "FFCC00")

def thin_border():

def check_machine_issues(item):
    """유해위험기계기구 누락·오기 검토. 이슈 문자열 반환, 정상이면 빈 문자열."""
    # review_issues가 이미 지정된 경우 그대로 사용
    if item.get("review_issues", "").strip():
        return item["review_issues"].strip()

    machine = item.get("유해위험기계기구", "").strip()
    context = (item.get("공정단계", "") + " " +
               item.get("유해위험요인", "") + " " +
               item.get("위험요인유형", "")).lower()

    issues = []

    # 1. 누락 검사: 컨텍스트에 기계 관련 키워드 있는데 기재 없음
    if not machine or machine in ("", "없음", "-"):
        for machine_name, keywords in HAZARD_MACHINES.items():
            if any(kw in context for kw in keywords):
                issues.append(f"[누락] '{machine_name}' 관련 작업으로 추정되나 기계기구 미기재")
                break

    # 2. 미등재 기계기구 검사
    elif machine not in ("해당없음", "없음", "-"):
        machine_lower = machine.lower().replace(" ", "")
        registered = False
        for machine_name, keywords in HAZARD_MACHINES.items():
            if (machine_name.replace(" ", "") in machine_lower or
                    machine_lower in machine_name.replace(" ", "") or
                    any(kw in machine_lower for kw in keywords)):
                registered = True
                break
        if not registered:
            issues.append(f"[미등재] '{machine}'은(는) 법정 유해위험기계기구 목록에 없음. 명칭 확인 필요")

    # 3. 불일치 검사: 화학적 위험요인에 기계기구 기재
    if machine and machine not in ("해당없음", "없음", "-", ""):
        hazard_type = item.get("위험요인유형", "").lower()
        if "화학" in hazard_type:
            mach_lower = machine.lower()
            mechanical_machines = ["크레인", "프레스", "지게차", "컨베이어", "로봇"]
            if any(m in mach_lower for m in mechanical_machines):
                issues.append(f"[불일치] 화학적 위험요인에 기계적 기계기구 '{machine}' 기재 — 검토 필요")

    return " / ".join(issues)

    score = item["가능성"] * item["중대성"]
    level_text, level_code, risk_color = get_risk_level(score)
    risk_fill = PatternFill("solid", fgColor=risk_color)

    # 유해위험기계기구 검토
    issue = check_machine_issues(item)
    has_issue = bool(issue)
    if has_issue:
        issue_summary.append(f"  행 {idx}: {issue}")

    machine_val = item.get("유해위험기계기구", "해당없음") or "해당없음"

    row_values = [
        ("A", idx),
        ("B", item["공정단계"]),
        ("C", item["유해위험요인"]),
        ("D", item["위험요인유형"]),
        ("E", machine_val),
        ("F", item["가능성"]),
        ("G", item["중대성"]),
        ("H", score),
        ("I", f"{level_text}\n({level_code}) {score}점"),
        ("J", item["감소대책"]),
        ("K", item.get("담당자", "")),
        ("L", item.get("완료예정일", "")),
        ("M", issue if has_issue else "✔ 정상"),
    ]

    for col, value in row_values:
        cell = ws[f"{col}{r}"]
        cell.value = value
        cell.border = thin_border()
        cell.alignment = center if col in "AFGHIKL" else left

        # 기본 폰트
        cell.font = data_font

        # E열(유해위험기계기구) 또는 M열(검토의견)에 이슈 있으면 붉은 폰트+배경
        if has_issue and col in ("E", "M"):
            cell.font = red_font
            cell.fill = red_fill
        elif col == "M" and not has_issue:
            cell.font = Font(name="맑은 고딕", size=10, color="00AA00")

    # 위험성 수준 셀 스타일
    ws[f"I{r}"].fill = risk_fill
    if risk_color in ("FF0000", "FF6600"):
        ws[f"I{r}"].font = Font(name="맑은 고딕", size=10, bold=True, color="FFFFFF")

# --- 범례 ---
legend_row = ROW_START + len(assessment_data["items"]) + 1
ws.merge_cells(f"A{legend_row}:M{legend_row}")
ws[f"A{legend_row}"] = (
    "【위험성 수준】 매우 높음(VH):20~25점 즉시 중지 | 높음(H):15~19점 즉시 개선 | "
    "보통(M):9~14점 단기 개선 | 낮음(L):4~8점 관리 유지 | 매우 낮음(VL):1~3점 허용  "
    "※ 붉은색 셀 = 유해위험기계기구 누락·오기 이슈"
)
ws[f"A{legend_row}"].font = Font(name="맑은 고딕", size=9, italic=True)
ws[f"A{legend_row}"].alignment = left
ws[f"A{legend_row}"].fill = PatternFill("solid", fgColor="FFF2CC")

# --- 파일 저장 ---
output_dir = os.getcwd()
filename = (
    f"위험성평가표_{assessment_data['작업명']}_{assessment_data['평가일']}.xlsx"
    .replace(" ", "_")
)
filepath = os.path.join(output_dir, filename)
wb.save(filepath)
print(f"✅ Excel 파일 생성 완료: {filepath}")

# --- 검토 결과 요약 출력 ---
from collections import Counter
levels = []
for item in assessment_data["items"]:
    s = item["가능성"] * item["중대성"]
    _, code, _ = get_risk_level(s)
    levels.append(code)
cnt = Counter(levels)

print("\n📊 위험성 수준 요약:")
for lvl in ["VH", "H", "M", "L", "VL"]:
    print(f"  {lvl}: {cnt.get(lvl, 0)}건")

if issue_summary:
    print(f"\n🔴 유해위험기계기구 검토 이슈 ({len(issue_summary)}건) — Excel에서 붉은색으로 표시:")
    for s in issue_summary:
        print(s)
else:
    print("\n✅ 유해위험기계기구 검토 이슈 없음 (전 항목 정상)")

Excel 파일이 생성되면 사용자에게:

**붉은색 표시 기준:**
- `[누락]` — 공정·위험요인에서 기계 관련 키워드 감지되나 기계기구 미기재
- `[미등재]` — 기재된 명칭이 법정 유해위험기계기구 목록에 없음
- `[불일치]` — 위험요인 유형과 기계기구가 논리적으로 맞지 않음
- `[형식오류]` — 불명확한 약어·비표준 명칭 사용
