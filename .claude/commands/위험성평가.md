# 작업위험성평가 지원 Skill

사용자와 대화하며 작업위험성평가표를 작성하고 Excel 파일로 출력합니다.
유해위험요인은 사고 원인→경로→결과를 구체적으로 기술하며, 사내 작업안전가이드가 제공된 경우 그 내용을 우선 반영합니다.
작성 완료 후 유해위험기계기구 누락·오기 여부를 자동 검토하여 Excel에 붉은 폰트로 표시합니다.

---

## 사내 작업안전가이드 활용 (STEP 0 — 최우선 실행)

**skill 시작 시 반드시 아래 순서대로 처리합니다:**

### 1. 채팅 첨부 파일 확인 (최우선)

사용자가 이번 채팅 메시지에 파일을 첨부한 경우:
- 첨부된 파일을 즉시 읽어 안전가이드 내용을 추출합니다.
- PDF라면 `Read` 도구로 파일 경로를 직접 읽습니다 (Claude는 PDF를 직접 읽을 수 있습니다).
- 추출한 내용을 아래 경로에 저장하여 세션 전반에서 참조합니다:

```
.claude/safety-guide/guide.txt
```

저장 시 파일 상단에 출처와 날짜를 기록합니다:
```
# 사내 작업안전가이드
# 출처: [첨부파일명]
# 등록일: [오늘날짜]
```

파일이 여러 개이거나 분량이 많아 한 번에 읽기 어려우면:
- 파일명과 총 페이지 수를 사용자에게 알립니다.
- 어떤 챕터/섹션이 이번 평가 작업과 관련 있는지 사용자에게 질문합니다.
- 해당 섹션만 우선 읽어 반영하고, 나머지는 필요 시 추가로 읽습니다.

### 2. 기존 저장 파일 확인

채팅에 첨부 파일이 없으면 `.claude/safety-guide/guide.txt` 파일이 있는지 확인합니다.
- 파일이 있으면 읽어서 이후 모든 단계에서 참조합니다.

### 3. 안전가이드 없는 경우

위 두 가지 모두 없으면 KOSHA 가이드라인 기준으로 진행하고, 사용자에게 다음과 같이 안내합니다:
> "사내 작업안전가이드가 없어 KOSHA 기준으로 진행합니다.
> 가이드 파일(PDF/Word/Excel)을 채팅에 첨부하면 사내 기준이 자동 반영됩니다."

### 안전가이드 반영 원칙

가이드가 준비된 경우 이후 단계에서 다음과 같이 반영합니다:
- **STEP 3** (위험요인 발굴): 가이드의 해당 작업·공정 섹션을 먼저 검색하여 위험요인 제안에 반영
- **STEP 5** (감소대책): 가이드에 명시된 대책·기준치를 그대로 인용, 출처 표기
  - 인용 형식: `[가이드 X장/X절] 대책 내용`
  - 가이드에 없는 항목은 KOSHA 기준 적용 후 `[KOSHA]` 표기

## 진행 절차

---

### STEP 1 — 기본 정보 수집

사용자에게 다음 항목을 질문하세요:

1. **사업장명** (회사/현장 이름)
2. **평가 대상 작업명** (예: 용접 작업, 지게차 하역 작업, 외벽 도장 작업 등)
3. **평가일** (오늘 날짜 기본 제안)
4. **평가자 이름**
5. **작업 장소** (건물동, 공정라인, 현장 위치 등)

---

### STEP 2 — 작업 공정/단계 도출

수집한 작업명을 바탕으로:
1. 해당 작업의 세부 단계(공정)를 **5~10개** 제안하세요.
2. 사용자가 수정·추가·삭제할 수 있도록 합니다.
3. 최종 공정 단계 목록을 확정합니다.

---

### STEP 3 — 공정별 유해위험요인 및 유해위험기계기구 발굴

#### 유해위험요인 작성 원칙 (구체성 필수)

유해위험요인은 아래 3요소를 모두 포함하여 **한 문장으로** 작성합니다:

```
[위험유형] (누가/무엇이) + (어떤 상황/조건에서) + (어떻게) → (예상 사고/질병)
```

**구체적 작성 예시 (올바른 예):**

| 구분 | 나쁜 예 (추상적) | 좋은 예 (구체적) |
|------|----------------|----------------|
| 기계 | [협착] 프레스 작업 중 협착 위험 | [협착] 슬라이드 행정 중 금형 교체를 위해 손을 삽입할 경우 → 손가락 절단·협착 |
| 추락 | [추락] 고소작업 중 추락 위험 | [추락] 3m 높이 철골 구조물 위에서 볼트 체결 작업 시 안전대 부착 설비 미설치 → 추락 사망 |
| 화학 | [화학] 유기용제 취급 중 건강장해 | [화학] 밀폐된 도장부스 내 우레탄계 도료(MEK 함유) 스프레이 분무 중 국소배기 미작동 시 → 유기용제 중독·직업성 천식 |
| 전기 | [감전] 전기작업 중 감전 위험 | [감전] 배전반 활선(220V) 상태에서 전류 측정기 연결 중 절연 불량 → 심실세동·감전사 |
| 중량물 | [요통] 중량물 취급 시 부상 | [근골격계] 25kg 이상 부품 박스를 하루 50회 이상 허리를 굽혀 반복 들기 → 요추 추간판 탈출증 |

**유해위험요인 유형 분류:**
- 기계적: 협착, 끼임, 절단, 충돌, 전도, 파열
- 전기적: 감전, 아크 플래시, 정전기 폭발
- 화학적: 흡입(가스·증기·분진), 피부 접촉, 눈 자극, 폭발
- 물리적: 소음성 난청, 진동장해, 고온(열사병), 저온(동상), 방사선
- 인간공학: 근골격계(요통·어깨·손목), 반복작업, 부적절한 자세
- 추락/낙하: 추락(고소), 낙하물 충격, 전도(미끄러짐)
- 화재/폭발: 인화성 물질 점화, 가스 누출 폭발, 분진 폭발

#### 유해위험기계기구 수집

### STEP 4 — 위험성 크기 산정

각 유해위험요인에 대해 **가능성 × 중대성** 방식으로 평가합니다.

**가능성 (발생 빈도/가능성):**
| 등급 | 점수 | 기준 |
|------|------|------|
| 매우 높음 | 5 | 매일 또는 매우 자주 발생 가능 |
| 높음 | 4 | 주 1회 이상 발생 가능 |
| 보통 | 3 | 월 1회 이상 발생 가능 |
| 낮음 | 2 | 연 1회 미만 발생 가능 |
| 매우 낮음 | 1 | 거의 발생하지 않음 |

**중대성 (사고 결과의 심각도):**
| 등급 | 점수 | 기준 |
|------|------|------|
| 매우 심각 | 5 | 사망 또는 영구 장애 |
| 심각 | 4 | 6개월 이상 요양 필요 부상 |
| 보통 | 3 | 1개월 이상 요양 필요 부상 |
| 경미 | 2 | 1개월 미만 치료 |
| 미미 | 1 | 응급처치 수준 |

**위험성 수준 판정:**
| 점수 | 위험성 수준 | 조치 |
|------|------------|------|
| 20~25 | 매우 높음 (VH) | 즉시 작업 중지, 긴급 대책 수립 |
| 15~19 | 높음 (H) | 즉시 개선 필요 |
| 9~14 | 보통 (M) | 단기 내 개선 계획 수립 |
| 4~8 | 낮음 (L) | 현 수준 관리, 정기 모니터링 |
| 1~3 | 매우 낮음 (VL) | 허용 가능, 기록 유지 |

### STEP 5 — 위험성 감소대책 수립

#### 감소대책 작성 원칙

1. **안전가이드 우선 반영**: `.claude/safety-guide/guide.txt`가 있으면 해당 작업·위험요인에 맞는 가이드 내용을 인용하고 출처 표기
   - 형식: `[가이드 X장 X절] 대책 내용`
2. **우선순위 준수**: 제거 → 대체 → 공학적 → 관리적 → 보호구
3. **구체성**: 장치명·규격·기준값·빈도를 포함

**구체적 감소대책 예시:**

| 위험요인 | 나쁜 예 (추상적) | 좋은 예 (구체적) |
|---------|----------------|----------------|
| 프레스 협착 | 방호장치 설치 | [공학적] 광전자식 방호장치(안전거리 200mm 이상) 설치 / [관리적] 운전 전 방호장치 작동 상태 일일 점검 기록 |
| 고소 추락 | 안전대 착용 | [공학적] 수직구명줄(직경 16mm 이상) 설치 / [관리적] 고소작업허가서 발급 후 작업 / [보호구] 전신안전대(KS G 8072) 착용 및 체결 확인 |
| 유기용제 흡입 | 환기 실시 | [공학적] 후드 흡인속도 0.5m/s 이상의 국소배기장치 가동 / [관리적] 밀폐공간 산소농도 18% 이상 작업 전 측정 / [보호구] 방독마스크(유기화합물용 정화통) 착용 |
| 감전 | LOTO 실시 | [관리적] 잠금·표지(LOTO) 절차서 작성 및 개인 잠금장치 적용 / [보호구] 절연장갑(1,000V급) 및 절연화 착용 / [공학적] 누전차단기(정격감도 30mA 이하) 설치 |

위험성 수준이 **보통(M) 이상**인 항목에 대해 우선적으로 수립하고, 각 항목마다 **2개 이상의 대책**을 제시합니다.

### STEP 6 — 유해위험기계기구 검토 (자동 수행)

Excel 생성 전에 아래 기준으로 각 항목을 검토합니다.
이슈가 있는 항목은 Excel에 붉은 폰트·배경으로 표시됩니다.

**검토 기준:**
| 검토 항목 | 판단 기준 | 오류 코드 |
|----------|----------|----------|
| **누락** | 공정·위험요인에 기계기구 키워드 있으나 미기재 | `[누락]` |
| **미등재** | 기재된 명칭이 법정 유해위험기계기구 목록 외 | `[미등재]` |
| **불일치** | 위험요인 유형과 기계기구가 논리적으로 불일치 | `[불일치]` |
| **형식오류** | 불명확한 약어·비표준 명칭 | `[형식오류]` |
