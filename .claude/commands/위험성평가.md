# 작업위험성평가 지원 Skill

사용자와 대화하며 작업위험성평가표를 작성하고 Excel 파일로 출력합니다.
각 작업단계의 유해위험기계기구·장소·작업특성을 종합 검토하여 위험요인을 발굴하고,
감소대책은 LG화학 작업안전가이드에 명시된 항목을 근로자 준수사항 형식으로 작성합니다.
작성 완료 후 유해위험기계기구 누락·오기 여부를 자동 검토하여 Excel에 붉은 폰트로 표시합니다.

---

## 최우선 원칙 — 사용자 형식 요구사항 준수

> **사용자가 평가서의 형식(양식·서식·컬럼·항목 구성 등)에 관한 요구사항을 제시하면
> 해당 요구사항을 최우선으로 따릅니다. 아래 기본 형식보다 사용자의 지시가 항상 우선합니다.**

### 형식 요구사항이 발생하는 경우

| 상황 | 처리 방법 |
|------|-----------|
| 사내 양식 파일(Excel/Word/PDF) 첨부 | 첨부 파일의 컬럼 구성·순서·명칭을 그대로 적용하여 출력 |
| 컬럼 추가·삭제·순서 변경 요청 | 즉시 반영하고 확인 후 진행 |
| 특정 항목 명칭 변경 요청 | 변경된 명칭을 Excel 헤더 및 대화 중 일관 사용 |
| 점수 체계 변경 요청 (예: 3×3 행렬) | 요청된 체계로 즉시 전환 |
| 출력 방식 변경 요청 (예: 마크다운 표, CSV) | 요청 방식으로 출력 |
| 작업 중 형식 수정 요청 | 즉시 반영하고, 이전에 작성된 항목도 동일 형식으로 소급 적용 |

### 형식 요구사항 미제시 시

사용자가 별도 형식을 지정하지 않으면 아래 기본 절차(STEP 1~7)를 따릅니다.

## STEP 0 — LG화학 작업안전가이드 로드 (최우선 실행)

**skill 시작 시 반드시 아래 순서대로 처리합니다:**

### 1. 채팅 첨부 파일 확인 (최우선)

사용자가 이번 채팅 메시지에 파일을 첨부한 경우:
- 첨부된 파일(PDF/Word/Excel)을 즉시 읽어 안전가이드 전체 내용을 파악합니다.
- 분량이 많으면 이번 평가 작업과 관련된 챕터/섹션을 사용자에게 확인하고 해당 부분을 우선 읽습니다.
- 추출한 내용을 아래 경로에 저장하여 세션 전반에서 참조합니다:

```
.claude/safety-guide/guide.txt
```

### 2. 기존 저장 파일 확인

채팅 첨부가 없으면 `.claude/safety-guide/guide.txt`를 읽어 참조합니다.

### 3. 가이드 없는 경우

위 두 가지 모두 없으면 KOSHA 기준으로 진행하고 사용자에게 안내합니다:
> "LG화학 작업안전가이드가 등록되어 있지 않아 KOSHA 기준으로 진행합니다.
> 가이드 파일(PDF/Word/Excel)을 채팅에 첨부하면 LG화학 기준이 자동 반영됩니다."

### 가이드 반영 원칙

가이드가 있으면 이후 단계에서:
- **STEP 3**: 가이드의 해당 작업·공정 섹션에서 위험요인 힌트를 먼저 확인
- **STEP 5**: 감소대책 전 항목을 가이드에서 검색하여 명시된 준수사항을 그대로 인용
  - 인용 형식: `[LG화학 가이드 X장 X절]`
  - 가이드에 없으면: `[KOSHA 기준]`

## STEP 1 — 기본 정보 수집

### 1-0. 사내 양식 확인 (가장 먼저)

기본 정보를 묻기 전에 아래 메시지를 전달합니다:

> "사내 위험성평가 양식(Excel/Word/PDF)이 있으면 지금 첨부해 주세요.
> 첨부하시면 해당 양식의 컬럼 구성·순서·항목명을 그대로 적용하여 작성합니다.
> 없으면 기본 양식으로 진행하겠습니다."

**사내 양식 첨부 시 처리:**
- 첨부 파일의 헤더(컬럼명)와 항목 구성을 파악합니다.
- 파악한 구조를 사용자에게 요약하여 확인합니다.
  > 예: "첨부 양식 확인했습니다. 컬럼 구성: No. / 작업단계 / 위험요인 / 위험도(빈도×강도) / 대책 / 담당부서 / 기한 — 이 순서로 작성하겠습니다."
- 이후 모든 단계의 출력(대화 중 표, Excel 생성)을 해당 양식에 맞춥니다.
- 양식에 없는 컬럼(예: 유해위험기계기구 검토)은 별도 주석 또는 하단 메모로 제공합니다.

### 1-1. 기본 정보 수집

사용자에게 다음 항목을 질문하세요 (한 번에 하나씩):

1. **사업장명**
2. **평가 대상 작업명** (예: 용접 작업, 지게차 하역, 외벽 도장 등)
3. **평가일** (오늘 날짜 기본 제안)
4. **평가자 이름**
5. **작업 장소** (건물동, 공정라인, 위치 등)

---

## STEP 2 — 작업 공정/단계 도출

수집한 작업명을 바탕으로:
1. 세부 작업 단계를 **5~10개** 제안합니다.
2. 사용자가 수정·추가·삭제합니다.
3. 최종 목록을 확정합니다.

---

## STEP 3 — 공정별 유해위험요인 발굴

### 3단계 종합 검토 (각 공정 단계마다 반드시 수행)

각 공정 단계를 분석할 때 아래 세 가지 관점을 **모두** 검토하여 위험요인을 발굴합니다.

#### ① 유해위험기계기구 관점
해당 단계에서 사용하는 기계기구를 파악하고, 그 기계기구 고유의 위험을 검토합니다.

| 기계기구 | 검토해야 할 고유 위험 |
|---------|-------------------|
| 프레스 | 슬라이드 행정 중 신체 삽입 → 협착·절단 |
| 크레인·호이스트 | 줄걸이 불량·과부하 → 낙하·충돌 / 선회 반경 내 접근 → 충돌 |
| 지게차 | 시야 불량 → 보행자 충돌 / 경사로 주행 → 전도 |
| 컨베이어 | 가동 중 이물질 제거 → 끼임 / 벨트 접촉 → 화상·끼임 |
| 고소작업대 | 2m 이상 작업 → 추락 / 전선 근접 → 감전 |
| 사출성형기 | 금형 사이 신체 삽입 → 협착 / 고온 수지 비산 → 화상 |
| 압력용기·보일러 | 안전밸브 미작동 → 폭발 / 고온 증기 누출 → 화상 |
| 롤러기 | 롤 사이 손 접촉 → 절단·협착 |
| 산업용 로봇 | 작업 반경 내 접근 → 충돌·협착 |
| 전단기·절곡기 | 날 부위 신체 접촉 → 절단 |
| 양중기·슬링 | 과부하·결함 달기기구 → 하중 낙하 |

**법정 유해위험기계기구 목록 (산업안전보건법):**
프레스 / 전단기·절곡기 / 크레인 / 리프트 / 압력용기 / 롤러기 / 사출성형기 / 고소작업대 / 컨베이어 / 산업용 로봇 / 지게차 / 양중기

#### ② 작업 장소 관점
작업이 이루어지는 장소의 특성에 따른 추가 위험을 검토합니다.

| 장소 특성 | 검토해야 할 위험 |
|---------|---------------|
| 고소(2m 이상) | 추락, 낙하물, 고소작업대 전도 |
| 밀폐공간 | 산소결핍, 유해가스 축적, 탈출 불가 |
| 옥외·야외 | 날씨(폭염·한파·우천), 강풍에 의한 낙하물 |
| 협소한 공간 | 탈출 제한, 환기 불량, 장비 회전반경 간섭 |
| 화학물질 취급 구역 | 누출·비산, 증기 흡입, 피부 접촉 |
| 전기실·변전설비 주변 | 활선 접촉, 아크 플래시 |
| 중량물 이동 통로 | 지게차·크레인과 보행자 동선 교차 |
| 고온·고압 설비 주변 | 화상, 폭발, 증기 누출 |
| 습윤·미끄러운 바닥 | 전도, 넘어짐 |

#### ③ 작업 특성 관점
작업의 방식·빈도·노출 수준에 따른 위험을 검토합니다.

| 작업 특성 | 검토해야 할 위험 |
|---------|---------------|
| 반복 작업(하루 50회↑) | 근골격계 질환(요통, 어깨, 손목) |
| 중량물 취급(남 25kg↑ / 여 15kg↑) | 요추 부상, 협착 |
| 화학물질 장시간 노출 | 직업성 질환(피부염, 폐질환, 신경독성) |
| 소음 작업(85dB↑) | 소음성 난청 |
| 단독 작업 | 사고 시 구조 지연 |
| 야간·교대 작업 | 주의력 저하, 피로 누적 |
| 비정형 작업(점검·수리·청소) | 절차 미비, 방호장치 해제 상태 노출 |
| 외부 협력업체 혼재 작업 | 소통 부재, 위험 정보 미공유 |
| 신규·미숙련 근로자 포함 | 안전 지식 부족 |

---

### 위험요인 작성 형식

위 세 관점을 종합한 후, 아래 형식으로 **구체적으로** 작성합니다:

```
[위험유형] (기계기구/장소/작업특성) + (어떤 상황/조건에서) + (어떻게) → (예상 사고/질병)
```

---

### 사고사례 검색 및 [사고사례] 표시 (각 공정 단계마다 수행)

위험요인을 도출한 직후, **각 위험요인에 대해 인터넷에서 유사 사고사례를 검색**하여
실제 발생한 재해와 연관성이 확인되면 `[사고사례]` 태그를 표시합니다.

#### 검색 방법

각 위험요인의 핵심 키워드(위험유형 + 작업환경)로 아래 우선순위로 검색합니다:

| 우선순위 | 검색 대상 | 검색 예시 |
|---------|----------|---------|
| 1순위 | 안전보건공단(KOSHA) 재해사례 | `site:kosha.or.kr 밀폐공간 질식 사고사례` |
| 2순위 | 고용노동부 중대재해 | `고용노동부 중대재해 지게차 충돌 사례` |
| 3순위 | 일반 뉴스·보도자료 | `컨베이어 끼임 사망 재해 사례` |

#### [사고사례] 표시 기준

| 구분 | 기준 | 처리 |
|------|------|------|
| **표시** | 동일 위험유형·유사 작업환경에서 실제 재해 발생 확인 | 위험요인 앞에 `[사고사례]` 태그 추가 + 사례 요약 1줄 기재 |
| **미표시** | 사례를 찾지 못한 경우 | 태그 없이 기본 형식 유지 |

#### 위험요인 출력 형식

**[사고사례] 있는 경우:**
```
[위험유형] [사고사례] (기계기구/장소/작업특성) + 조건 → 예상사고
※ 사고사례: (발생 연도·장소·개요 1줄) — 출처: KOSHA/고용노동부 등
```

**[사고사례] 없는 경우:**
```
[위험유형] (기계기구/장소/작업특성) + 조건 → 예상사고
```

#### 주요 위험유형별 검색 키워드 예시

| 위험유형 | 검색 키워드 |
|---------|-----------|
| 밀폐공간 질식 | `밀폐공간 질식 사망 사고사례 KOSHA`, `맨홀 산소결핍 재해` |
| 회전체 끼임·협착 | `컨베이어 끼임 사망`, `롤러기 협착 재해사례`, `프레스 손가락 절단` |
| 고소 추락 | `고소작업 추락 사망 사례`, `비계 추락 재해 KOSHA` |
| 지게차 충돌 | `지게차 보행자 충돌 사망`, `지게차 협착 재해` |
| 크레인 낙하 | `크레인 낙하 사망 사고`, `줄걸이 불량 재해사례` |
| 감전 | `활선 감전 사망 사례`, `전기작업 감전 재해 KOSHA` |
| 화학물질 | `유기용제 중독 사례`, `화학물질 흡입 직업병` |
| 폭발·화재 | `가스 폭발 사고사례`, `인화성 물질 화재 재해` |

**예시 (사고사례 반영 후):**

| 공정 단계 | 발굴된 위험요인 |
|---------|--------------|
| 프레스 가동 | [협착] **[사고사례]** 프레스(기계기구) 슬라이드 행정 중 금형 이물질 제거를 위해 손을 금형 내부에 삽입할 경우 → 손가락 절단·협착<br>※ 사고사례: 2022년 경기도 제조업체, 프레스 이물질 제거 중 방호장치 미작동으로 우측 검지 절단 — 출처: KOSHA |
| 지게차 하역(창고 내) | [충돌] **[사고사례]** 지게차(기계기구) + 협소한 창고 통로(장소) + 보행자·차량 혼재(작업특성)로 시야 확보 불량 → 보행자 충돌·압사<br>※ 사고사례: 2023년 물류창고, 후진 지게차에 보행 근로자 압착 사망 — 출처: 고용노동부 중대재해 |

## STEP 4 — 위험성 크기 산정

각 유해위험요인에 대해 **가능성 × 중대성** 방식으로 평가합니다.

**가능성 (1~5):**
| 점수 | 기준 |
|------|------|
| 5 | 매일 또는 매우 자주 발생 가능 |
| 4 | 주 1회 이상 발생 가능 |
| 3 | 월 1회 이상 발생 가능 |
| 2 | 연 1회 미만 발생 가능 |
| 1 | 거의 발생하지 않음 |

**중대성 (1~5):**
| 점수 | 기준 |
|------|------|
| 5 | 사망 또는 영구 장애 |
| 4 | 6개월 이상 요양 필요 부상 |
| 3 | 1개월 이상 요양 필요 부상 |
| 2 | 1개월 미만 치료 |
| 1 | 응급처치 수준 |

**위험성 수준:**
| 점수 | 수준 | 조치 |
|------|------|------|
| 20~25 | 매우 높음 (VH) | 즉시 작업 중지, 긴급 대책 수립 |
| 15~19 | 높음 (H) | 즉시 개선 필요 |
| 9~14 | 보통 (M) | 단기 내 개선 계획 수립 |
| 4~8 | 낮음 (L) | 현 수준 관리, 정기 모니터링 |
| 1~3 | 매우 낮음 (VL) | 허용 가능, 기록 유지 |

## STEP 5 — 위험성 감소대책 (LG화학 근로자 준수사항)

### 작성 원칙

감소대책은 **근로자가 현장에서 직접 실행할 수 있는 준수사항** 형식으로 작성합니다.

1. **LG화학 작업안전가이드 최우선**: 가이드에서 해당 위험요인 관련 항목을 검색하여 명시된 준수사항을 그대로 인용합니다.
   - 출처 표기: `[LG화학 가이드 X장 X절]`
2. **가이드에 없는 경우**: KOSHA 기준을 적용하고 `[KOSHA]` 표기합니다.
3. **작성 방식**: 추상적 대책 표현 금지. 근로자가 읽고 바로 행동할 수 있도록 **동사+구체적 행동**으로 작성합니다.
4. **우선순위**: 제거 → 대체 → 공학적 → 관리적 → 보호구 순서로 나열합니다.
5. **항목 수**: 각 위험요인마다 **2개 이상** 준수사항을 제시합니다.

### 출력 형식

```
[LG화학 작업안전가이드 준수사항]
1. (근로자가 해야 할 구체적 행동)  [LG화학 가이드 X장 X절]
2. (근로자가 해야 할 구체적 행동)  [LG화학 가이드 X장 X절]
3. (근로자가 해야 할 구체적 행동)  [KOSHA]
```

### 준수사항 작성 예시

| 위험요인 | 나쁜 예 (추상적) | 좋은 예 (LG화학 준수사항 형식) |
|---------|----------------|-------------------------------|

> **주의**: 가이드가 없을 때는 위 출처를 `[KOSHA]`로 대체하여 동일한 준수사항 형식으로 작성합니다.
