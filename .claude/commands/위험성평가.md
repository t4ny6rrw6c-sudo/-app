# 작업위험성평가 지원 Skill

사용자와 대화하며 작업위험성평가표를 작성하고 Excel 파일로 출력합니다.

## 진행 절차

아래 순서대로 사용자에게 질문하며 정보를 수집하세요. 단계별로 완료된 후 다음 단계로 진행합니다.

---

### STEP 1 — 기본 정보 수집

사용자에게 다음 항목을 질문하세요:

1. **사업장명** (회사/현장 이름)
2. **평가 대상 작업명** (예: 용접 작업, 지게차 하역 작업, 외벽 도장 작업 등)
3. **평가일** (오늘 날짜 기본 제안)
4. **평가자 이름**
5. **작업 장소** (건물동, 공정라인, 현장 위치 등)

---

### STEP 2 — 작업 공정/단계 도출

수집한 작업명을 바탕으로:
1. 해당 작업의 세부 단계(공정)를 **5~10개** 제안하세요.
2. 사용자가 수정·추가·삭제할 수 있도록 합니다.
3. 최종 공정 단계 목록을 확정합니다.

**업종별 참고 유해위험요인 유형:**
- 기계적: 협착, 끼임, 절단, 충돌, 전도
- 전기적: 감전, 정전기, 아크
- 화학적: 유해물질 흡입, 피부 접촉, 폭발
- 물리적: 소음, 진동, 고온, 저온, 방사선
- 인간공학: 중량물 취급, 반복 동작, 부자연 자세
- 추락/낙하: 고소 작업, 낙하물
- 화재/폭발: 인화성 물질, 가스 누출

---

### STEP 3 — 공정별 유해위험요인 발굴

각 공정 단계마다 순서대로:

1. 해당 단계에서 **발생 가능한 유해위험요인** 2~4개를 제안하세요 (원인 및 현상 포함)
2. 사용자가 확인·수정하도록 합니다

유해위험요인 작성 형식:
> **[위험요인 유형]** 원인/현상 → 발생 가능 사고/질병

예시:
> **[협착]** 컨베이어 가동 중 점검 → 손가락 협착
> **[추락]** 2m 이상 고소작업 중 안전대 미착용 → 추락 재해

---

### STEP 4 — 위험성 크기 산정

각 유해위험요인에 대해 **가능성 × 중대성** 방식으로 평가합니다.

**가능성 (발생 빈도/가능성):**
| 등급 | 점수 | 기준 |
|------|------|------|
| 매우 높음 | 5 | 매일 또는 매우 자주 발생 가능 |
| 높음 | 4 | 주 1회 이상 발생 가능 |
| 보통 | 3 | 월 1회 이상 발생 가능 |
| 낮음 | 2 | 연 1회 미만 발생 가능 |
| 매우 낮음 | 1 | 거의 발생하지 않음 |

**중대성 (사고 결과의 심각도):**
| 등급 | 점수 | 기준 |
|------|------|------|
| 매우 심각 | 5 | 사망 또는 영구 장애 |
| 심각 | 4 | 6개월 이상 요양 필요 부상 |
| 보통 | 3 | 1개월 이상 요양 필요 부상 |
| 경미 | 2 | 1개월 미만 치료 |
| 미미 | 1 | 응급처치 수준 |

**위험성 수준 판정:**
| 점수 | 위험성 수준 | 조치 |
|------|------------|------|
| 20~25 | 매우 높음 (VH) | 즉시 작업 중지, 긴급 대책 수립 |
| 15~19 | 높음 (H) | 즉시 개선 필요 |
| 9~14 | 보통 (M) | 단기 내 개선 계획 수립 |
| 4~8 | 낮음 (L) | 현 수준 관리, 정기 모니터링 |
| 1~3 | 매우 낮음 (VL) | 허용 가능, 기록 유지 |

---

### STEP 5 — 위험성 감소대책 수립

위험성 수준이 **보통(M) 이상**인 항목에 대해 우선적으로 감소대책을 수립합니다.

대책 수립 우선순위 (제거 → 대체 → 공학적 → 관리적 → 보호구):

1. **제거**: 위험 요인 자체를 없앰
2. **대체**: 덜 위험한 방법/재료로 변경
3. **공학적 대책**: 방호장치, 격리, 환기 설치
4. **관리적 대책**: 작업절차서, 교육, 표지판, 출입 통제
5. **개인보호구**: 안전모, 안전대, 보호장갑 등

각 위험요인마다 위 우선순위에 따라 **1개 이상의 대책**을 제시하세요.

---

### STEP 6 — Excel 파일 생성

모든 정보 수집 후 아래 Python 스크립트를 실행하여 Excel 파일을 생성합니다.

수집된 데이터를 스크립트 내 `assessment_data` 변수에 채워 실행하세요.

```python
import openpyxl
from openpyxl.styles import (
    Font, Alignment, PatternFill, Border, Side
)
from openpyxl.utils import get_column_letter
from datetime import date
import os

# ===== 여기에 수집한 데이터를 입력 =====
assessment_data = {
    "사업장명": "",
    "작업명": "",
    "평가일": str(date.today()),
    "평가자": "",
    "작업장소": "",
    "items": [
        # {
        #   "공정단계": "단계명",
        #   "유해위험요인": "요인 설명",
        #   "위험요인유형": "유형",
        #   "가능성": 3,
        #   "중대성": 3,
        #   "현재안전조치": "기존 조치 내용",
        #   "감소대책": "개선 대책",
        #   "담당자": "",
        #   "완료예정일": ""
        # },
    ]
}
# =========================================

def get_risk_level(score):
    if score >= 20: return ("매우 높음", "VH", "FF0000")
    elif score >= 15: return ("높음", "H", "FF6600")
    elif score >= 9: return ("보통", "M", "FFCC00")
    elif score >= 4: return ("낮음", "L", "00CC00")
    else: return ("매우 낮음", "VL", "0070C0")

def thin_border():
    t = Side(style='thin')
    return Border(left=t, right=t, top=t, bottom=t)

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "위험성평가표"

# 열 너비 설정
col_widths = [5, 18, 28, 14, 8, 8, 8, 14, 28, 12, 14]
for i, w in enumerate(col_widths, 1):
    ws.column_dimensions[get_column_letter(i)].width = w

# --- 헤더 영역 ---
header_fill = PatternFill("solid", fgColor="1F4E79")
header_font = Font(name="맑은 고딕", bold=True, color="FFFFFF", size=11)
title_font  = Font(name="맑은 고딕", bold=True, size=16)
sub_font    = Font(name="맑은 고딕", size=10)
center      = Alignment(horizontal="center", vertical="center", wrap_text=True)
left        = Alignment(horizontal="left",   vertical="center", wrap_text=True)

ws.row_dimensions[1].height = 40
ws.merge_cells("A1:K1")
ws["A1"] = "작 업 위 험 성 평 가 표"
ws["A1"].font = title_font
ws["A1"].alignment = center
ws["A1"].fill = PatternFill("solid", fgColor="1F4E79")
ws["A1"].font = Font(name="맑은 고딕", bold=True, size=16, color="FFFFFF")

# 기본 정보
info_fill = PatternFill("solid", fgColor="D6E4F0")
info_label_font = Font(name="맑은 고딕", bold=True, size=10)

info_rows = [
    ("A2", "B2", "사업장명", "C2", "D2", assessment_data["사업장명"],
     "E2", "F2", "평가일",   "G2", "H2", assessment_data["평가일"]),
    ("A3", "B3", "작업명",   "C3", "D3", assessment_data["작업명"],
     "E3", "F3", "작업장소", "G3", "H3", assessment_data["작업장소"]),
    ("A4", "B4", "평가자",   "C4", "D4", assessment_data["평가자"],
     "E4", "F4", "",         "G4", "H4", ""),
]

for row_data in info_rows:
    lc1, lc2, lv1, vc1, vc2, vv1, lc3, lc4, lv2, vc3, vc4, vv2 = row_data
    ws.merge_cells(f"{lc1}:{lc2}")
    ws[lc1] = lv1
    ws[lc1].font = info_label_font
    ws[lc1].fill = info_fill
    ws[lc1].alignment = center
    ws[lc1].border = thin_border()

    ws.merge_cells(f"{vc1}:{vc2}")
    ws[vc1] = vv1
    ws[vc1].font = sub_font
    ws[vc1].alignment = left
    ws[vc1].border = thin_border()

    ws.merge_cells(f"{lc3}:{lc4}")
    ws[lc3] = lv2
    ws[lc3].font = info_label_font
    ws[lc3].fill = info_fill
    ws[lc3].alignment = center
    ws[lc3].border = thin_border()

    ws.merge_cells(f"{vc3}:{vc4}")
    ws[vc3] = vv2
    ws[vc3].font = sub_font
    ws[vc3].alignment = left
    ws[vc3].border = thin_border()

ws.row_dimensions[2].height = 20
ws.row_dimensions[3].height = 20
ws.row_dimensions[4].height = 20

# --- 컬럼 헤더 ---
ws.row_dimensions[5].height = 35
ws.row_dimensions[6].height = 35

headers_row5 = [
    ("A5:A6", "No."),
    ("B5:B6", "작업\n공정/단계"),
    ("C5:C6", "유해위험요인\n(원인/현상 → 예상사고)"),
    ("D5:D6", "위험요인\n유형"),
    ("E5:G5", "위험성 크기"),
    ("H5:H6", "위험성\n수준"),
    ("I5:I6", "위험성 감소대책"),
    ("J5:J6", "담당자"),
    ("K5:K6", "완료\n예정일"),
]
sub_headers = [("E6", "가능성\n(1~5)"), ("F6", "중대성\n(1~5)"), ("G6", "점수")]

for cell_range, text in headers_row5:
    ws.merge_cells(cell_range)
    start = cell_range.split(":")[0]
    ws[start] = text
    ws[start].font = header_font
    ws[start].fill = header_fill
    ws[start].alignment = center
    ws[start].border = thin_border()

for cell, text in sub_headers:
    ws[cell] = text
    ws[cell].font = header_font
    ws[cell].fill = header_fill
    ws[cell].alignment = center
    ws[cell].border = thin_border()

# --- 데이터 행 ---
ROW_START = 7
for idx, item in enumerate(assessment_data["items"], 1):
    r = ROW_START + idx - 1
    ws.row_dimensions[r].height = 45

    score = item["가능성"] * item["중대성"]
    level_text, level_code, color = get_risk_level(score)
    risk_fill = PatternFill("solid", fgColor=color)
    data_font = Font(name="맑은 고딕", size=10)

    row_values = [
        (f"A{r}", idx),
        (f"B{r}", item["공정단계"]),
        (f"C{r}", item["유해위험요인"]),
        (f"D{r}", item["위험요인유형"]),
        (f"E{r}", item["가능성"]),
        (f"F{r}", item["중대성"]),
        (f"G{r}", score),
        (f"H{r}", f"{level_text}\n({level_code}) {score}점"),
        (f"I{r}", item["감소대책"]),
        (f"J{r}", item.get("담당자", "")),
        (f"K{r}", item.get("완료예정일", "")),
    ]

    for cell_addr, value in row_values:
        cell = ws[cell_addr]
        cell.value = value
        cell.font = data_font
        cell.border = thin_border()
        cell.alignment = center if cell_addr[0] in "ADEFGJK" else left

    ws[f"H{r}"].fill = risk_fill
    if color in ("FF0000", "FF6600"):
        ws[f"H{r}"].font = Font(name="맑은 고딕", size=10, bold=True, color="FFFFFF")

# --- 범례 ---
legend_row = ROW_START + len(assessment_data["items"]) + 1
ws.merge_cells(f"A{legend_row}:K{legend_row}")
ws[f"A{legend_row}"] = (
    "【위험성 수준】  매우 높음(VH): 20~25점 — 즉시 중지  |  "
    "높음(H): 15~19점 — 즉시 개선  |  "
    "보통(M): 9~14점 — 단기 개선  |  "
    "낮음(L): 4~8점 — 관리 유지  |  "
    "매우 낮음(VL): 1~3점 — 허용"
)
ws[f"A{legend_row}"].font = Font(name="맑은 고딕", size=9, italic=True)
ws[f"A{legend_row}"].alignment = left
ws[f"A{legend_row}"].fill = PatternFill("solid", fgColor="F2F2F2")

# 파일 저장
output_dir = os.getcwd()
filename = f"위험성평가표_{assessment_data['작업명']}_{assessment_data['평가일']}.xlsx".replace(" ", "_")
filepath = os.path.join(output_dir, filename)
wb.save(filepath)
print(f"✅ Excel 파일 생성 완료: {filepath}")
```

## 안전가이드 파일 활용

사용자가 `/위험성평가` 실행 시 PDF/Word/Excel 형태의 사내 안전가이드 파일을 함께 첨부하면:
- 해당 파일의 내용을 읽어 업종별 위험요인 발굴에 반영
- 사내 기준의 감소대책 우선 적용

## 주의사항

- 각 단계에서 수집한 내용을 다음 단계 시작 전 요약하여 사용자에게 확인받으세요.
- 위험성 점수 산정 시 현재 안전조치가 없는 상태(무방비)를 기준으로 평가합니다.
- 감소대책은 제거→대체→공학적→관리적→보호구 순서 우선순위를 반드시 따르세요.
- 평가 완료 후 "사후관리"를 위해 담당자와 완료예정일 입력을 권장합니다.
